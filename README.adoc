= Cytoville
:toc:
// SPDX-License-Identifier: CC-BY-SA-4.0

A turn-based protist life simulation and time-management strategy set on a city map.
Develop one cell through its lifetime: travel, feed, work, study gene expression,
express organelles, regulate stress and complete an ontogenetic quest checklist.
This is individual-cell development, not population evolution.

== Native game

Rust owns every game rule and save. Bevy presents the city and cell.
Evil Weevil's real Zig kernel runs by default for the solo rival; the host translates
its intentions into legal biological actions. Enaction records causal decision
traces and supplies the presentation clock. Idris2 defines the versioned ABI.
Elixir supervises authoritative Rust workers for two-player sessions.
UMS compiles data packages consumed by this same game.

The native port carries all seven specimens, three scenarios, three difficulties,
21 organelles, 12 courses, three careers, weather, encounters, rival interactions,
encystment, checkpoints, mitosis and saves from the supplied browser prototype.
The browser implementation is not a runtime dependency.

== Quick start

Use Linux or WSL with graphics support, Rust, Zig 0.16.0, Idris2 0.8.0 and
Elixir 1.19 / Erlang OTP 28. Bevy's Linux build needs a C compiler, pkg-config,
ALSA, udev and X11/Wayland development libraries. Windows/macOS builds are not
yet certified by this repository's validation record.

[source,bash]
----
git clone --recurse-submodules https://github.com/catachresis-colloquium/cytoville
cd cytoville
just build
just run
----

Choose a specimen and scenario, then a district and action. Travel spends ATP.
Nutrition and stress affect growth and the next cycle's energy. Space ends your
turn; F5 saves and F9 loads. Accepted solo commands autosave. Escape opens the
menu. M toggles the procedural soundtrack. The client accepts `--package FILE`
for validated UMS content.

== Multiplayer

[source,bash]
----
cargo build -p cytoville-runtime
cd server
CYTOVILLE_WORKER=../target/debug/cytoville-server mix run --no-halt
----

In another terminal, run `cargo run -p cytoville-bevy -- --host --session pond`.
Give the displayed invitation key to the second player, who runs
`cargo run -p cytoville-bevy -- --join --session pond --key INVITATION`.
The server defaults to loopback port 4280. This is a private-host protocol;
internet deployment needs an authenticated encrypted transport in front of it.
See link:docs/architecture/MULTIPLAYER.adoc[protocol and operational limits].

Each client saves its private resume ticket to `cytoville-connection.json`;
restart with `--resume-file cytoville-connection.json`. Use separate
`--connection-file FILE` paths for two clients running in the same directory.

== Modding

[source,bash]
----
cargo run -p cytoville-ums -- init source.json
# Edit balance, scenarios and content within the versioned biological ontology.
cargo run -p cytoville-ums -- validate source.json
cargo run -p cytoville-ums -- preview source.json 7
cargo run -p cytoville-ums -- compile source.json . cytoville-package.json
cargo run -p cytoville-bevy -- --package cytoville-package.json
----

link:profiles/cytoville/v1/descriptor.json[The UMS profile] describes districts,
organelles, courses and cell-cycle quests. It imposes no platformer geometry,
gravity, jumping or horizontal camera assumptions.
See link:docs/architecture/UMS.adoc[UMS integration].

== Verification and status

`just test` runs rules/runtime/profile tests, the real Zig boundary tests, Idris
generation checks and an Elixir test using two TCP clients and a real Rust worker.
`just verify-budget` checks the production resource functions through
Creusot/Pearlite, with its proof toolchain installed separately.

This is a native alpha. The proof scope is deliberately narrower than the game:
see link:docs/verification/PROOF-STATUS.adoc[proof status],
link:docs/verification/VALIDATION.adoc[validation] and
link:docs/status/ROADMAP.adoc[remaining work]. No whole-game proof is claimed.

== AI-Assisted Installation

Read `CLAUDE.md`, `coordination.k9`, the repository deed and this README.
Install the declared tools with `mise trust` and `mise install`, initialise the
submodule, run `just doctor`, `just build` and `just test`.
The ABI is generated from Idris2; never hand-edit its generated constants.
Preserve the single Rust authority and the biological ontology.
