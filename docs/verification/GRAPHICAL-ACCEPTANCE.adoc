== Performance changes and limits

Idle rename no longer marks the whole UI dirty every frame. A regression test
checks 120 idle updates and Escape closure. Cell pulsing now changes a UI
transform on fixed steps rather than changing layout width every render frame.
The Bevy tests and updated native build passed before the graphical run.

Remaining: release-build frame-time measurements on the target GPU, broad window
size/DPI and accessibility testing, complete scenario/end-game coverage, two
simultaneous graphical human clients, and art/sound/game-feel acceptance.
The separate existing transport suite covers two human clients and rejects
untrusted certificates and mismatched hostnames; those tests are not graphical.
