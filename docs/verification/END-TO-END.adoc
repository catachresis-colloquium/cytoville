== Scope

Bevy now consumes the complete validated authoritative runtime, including Enaction
traces and Evil Weevil memory. Reconnects validate the snapshot and reject content
changes. Accepted human commands enter the causal trace, so two-human sessions
produce evidence even while the native rival is disabled.

Elixir offers both human multiplayer and server-hosted native-rival sessions.
Atomic, synchronized private checkpoints retain credentials, content, game state,
trace and native memory. Resume restores a stopped session or restarted service
through the Rust load validator. Expiry messages carry a lease to prevent an old
timer expiring a recently active session.

== Limits

Runtime responses carry content once, inside `runtime`. The worker checks the
serialized response against the 8 MiB transport limit, reserving 1 KiB for the
host's credential envelope, before committing a state transition. A session
whose response would exceed that bound rejects the transition without an
acknowledgement or mutation.

Dormant recovery checks the join/resume credential before starting a worker.
Restoring a checkpoint preserves its stored expiry until authentication succeeds.
Accepted commands and seat changes are checkpointed immediately. Idle polling
refreshes the in-memory lease and checkpoints the lease at most once per
`min(30 seconds, TTL / 4)`. After a crash, the durable inactivity deadline can
therefore be earlier than the latest poll by up to that interval. Startup removes
expired or invalid checkpoints and interrupted temporary writes; loading an
expired checkpoint also deletes it.

Tests exercise Bevy's real networking code headlessly, not graphical input.
The checkpoint store is single-host and has not been certified for power loss,
network filesystems or distributed operation. Public encrypted ingress, backup
policy and disk quotas remain deployment work. Existing Creusot proof coverage
is unchanged; these integration changes are tested, not newly formally proven.
No new release archive was produced. Existing organisation Actions allowlist
restrictions are unchanged. Hosted CI results are separate from local evidence.
