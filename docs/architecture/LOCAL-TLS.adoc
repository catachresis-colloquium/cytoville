== Operation

The Elixir listener stays bound to loopback. Set both `CYTOVILLE_TLS_CERT` and
`CYTOVILLE_TLS_KEY` to PEM files before starting `mix run --no-halt`. A missing
half of the pair prevents startup. TLS 1.2 and 1.3 are accepted.

Connect Bevy with `--server tls://localhost:4280 --host --session NAME`.
For a private local CA, set `CYTOVILLE_CA_CERT` on each client to its PEM certificate.
The client checks trust and the hostname, including on resume; no insecure mode
is provided. Without TLS, clients refuse non-loopback destinations.

`CYTOVILLE_E2E_TLS=1 bash scripts/cytoville-e2e.sh` generates a one-day localhost
certificate in a private temporary directory. It runs untrusted-certificate and
wrong-hostname rejection checks, then the real UMS, multiplayer, reconnect and
native-rival scenario over TLS. Temporary keys are removed when the test exits.
The standard CI script runs both plaintext-loopback and TLS variants.
