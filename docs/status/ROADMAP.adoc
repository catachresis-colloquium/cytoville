== Native alpha

The authoritative engine, Bevy client, actual Zig rival, Enaction traces, Idris
contract, Elixir two-player server and UMS package adapter form the native path.

== Remaining release work

* Establish a frame-time and input-latency baseline on the target machine in a
  release build; profile rendering, UI rebuilds, native turns and networking.
  Idle rename redraws, layout-changing pulse animation and repeated portrait
  rasterisation have been corrected. Bounded debug/software-renderer samples
  are recorded in docs/verification/PERFORMANCE.adoc; hardware release and
  end-to-end input measurements remain open.
* Continue the city's visual identity and game feel. The native map now has
  illustrated district landmarks, curved paths, ambient particles and moving
  player/rival markers. It remains an engineering alpha; richer organism
  animation, sound acceptance, readability at other sizes and human art/game-feel
  acceptance are unfinished.
* Retain the allowed compatible Creusot backport until any later suite adoption
  is separately validated. The canonical parser correction (#92 in cicd-suite)
  is merged; Cytoville's backport passed hosted run 42365155854. Those receipts
  cover one caller repository and its three selected resource functions.
* Expand Creusot coverage from resource primitives to full command invariants.
* Certify Windows/macOS packaging and a reproducible game/proof build image.
* Finish visual and sound parity with the browser prototype and accessibility.
* Certify checkpoint backups, disk quotas and production encrypted ingress.
* Playtest rival strategy and scenario balance with humans.
* Build the dedicated UMS graphical city/cell editor over the executable profile.

No item on this list is represented as completed verification.

== Future computing and responsiveness follow-up, 2026-11-07

* Implemented a local Settings / Future computing research catalogue with nine
  technology groups, disabled activation, explanations and opt-in source links.
  No specialist backend or hardware probe is represented as implemented.
* Added a regression check that disabled activation and settings keyboard input
  cannot advance the game. Native DX12 rendering of the catalogue was inspected.
* Replaced the inherited placeholder contribution guide with Cytoville-specific
  build, research, accessibility and evidence guidance.
* Recorded proposed shared Enaction integration, GSA capabilities and Mathesis
  applications in docs/architecture/FUTURE-COMPUTING.adoc. GSA live adapters,
  quantum solvers and reversible energy-recovery backends remain unimplemented.
* The owner reports pervasive input/window/startup/shutdown slowness. Application
  update cadence does not establish click-to-display response. PresentMon 2.6.0
  refused ETW capture with access denied; no Windows permissions were changed.
  Added scoped startup/exit timings and optional queue/audio diagnostic switches.
  Root cause and a validated responsiveness fix remain open.
* Fixed district illustration hit targets, same-destination feedback without
  another command, marker placement at the actual landmark and a bounded visual
  journey that does not teleport after one delayed frame. Added rerouting/hitch
  tests and a graphical picture-click/repeat-click check; the full local journey
  passes. This addresses the identified map defects, not all reported latency.
* The owner's clarified tabbed Settings and actual accelerator implementation
  scope is recorded in SETTINGS-AND-ACCELERATION.adoc. The large research catalogue
  is intermediate and must not be mistaken for completion of that scope.

== Functional acceptance on 2026-11-07

The bounded X11 graphical journey and loopback TLS/native-rival reconnect passed
locally after the owner authorised a Debian restart. The executable acceptance
script is wired into Rust CI with screenshot retention. Its CI run must pass
independently; local success is not a substitute. See GRAPHICAL-ACCEPTANCE.adoc
under docs/verification for scope and remaining coverage.
