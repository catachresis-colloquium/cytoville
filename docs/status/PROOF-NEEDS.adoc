at `7641c7fdb01420696b5420ab85d88f599f32f609`.

Production Rust contracts must apply to the implementation called by the game.
Idris contract proofs do not establish Rust or Zig implementation correctness.
Concrete ABI layouts need target checks; pointer validity and lifetime are
separate obligations from size arithmetic.

Remaining obligations: full command-state invariant preservation, all resource
conversions, serialization roundtrips for every valid state, native-rival
termination, FFI memory safety, and multiplayer authorization/concurrency
correctness. These remain open even where bounded tests pass.

See link:../verification/PROOF-STATUS.adoc[the ledger] for completed scopes.
