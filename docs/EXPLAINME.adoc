= How Cytoville works
// SPDX-License-Identifier: CC-BY-SA-4.0

`cytoville-core` owns cell state and deterministic commands. Bevy presents the
city, action costs, encounters and quest progress. The local game and the
Elixir-supervised server use the same Rust authority.

The native rival calls Evil Weevil through a Zig C ABI. Idris2 generates shared
layout constants; Rust, Zig and C check their concrete layouts. Enaction records
causal decision traces and supplies the presentation clock.

UMS supplies a biological simulation profile and data-package compiler. The
game verifies each package's digest, typed content and references before use.

Creusot/Pearlite proves the production budget primitives. Most game logic is
tested-only: differential browser fixtures, scenario runs, save replay, native
ABI tests and two real multiplayer clients. See `verification/PROOF-STATUS.adoc`
and `status/ROADMAP.adoc` for exact boundaries.

The RSR template's session dispatcher, contractiles, deed and arrival pack
provide engineering governance. Their presence is not evidence that every
inherited release gate has passed.
